# v0.1.0

## Goal

Prove the end-to-end path:

```text
Resource.dll + original assets -> parser -> core state -> SDL2 window -> screen
```

## Included

- Cargo workspace and crate boundaries.
- `Resource.dll` PE resource parser with case-insensitive lookup.
- `SPLASHSCREENS.XUI` parser.
- SDL2 800x600 window.
- Splash sequence with the original timing constants.
- Title background screen.
- `aaatw-extract` CLI.
- CI for Windows, Linux, and macOS.

## Not included yet

- Gameplay, levels, puzzles, scoring, missions, journal, map, PDA.
- Audio (BASS replacement).
- Save/config and registry mapping.
- Full XUI rendering (labels, buttons, containers, cursors, fonts).
- Loose-file asset override precedence (partially implemented).
- Localisation beyond the original resource strings.
- Static musl Linux builds (the bundled SDL2 CMake build does not yet cross-compile
  cleanly to musl in this setup).

## Running

```sh
cargo build --release -p aaatw-cli
cd "/path/to/Amazing Adventures Around the World"
/path/to/aaatw
```

If the binary is not next to `Resource.dll`, pass the asset directory explicitly:

```sh
aaatw --data-dir "/path/to/Amazing Adventures Around the World"
```
